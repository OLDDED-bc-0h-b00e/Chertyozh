# Доска идей

1. Прочитай `brief/BOARD.md` целиком: там сводка по разделам.
2. Открой картинки из `brief/assets/`, на которые ссылается задача (`Read` показывает PNG/SVG). Итоговый макет: `brief/assets/wire-3c-final.svg`.
3. Нужны координаты или связи карточек — смотри `brief/board.json`, иначе не трать на него контекст.
4. Разложи для себя:
   - «Решения» со статусом «Принято» — обязательные требования.
   - «Не хочу» — анти-референсы, их нельзя нарушать.
   - «Вопросы» — задай пользователю (AskUserQuestion), ответы не придумывай.
5. Если в задаче есть что-то, противоречащее доске, скажи об этом до правок.

`brief/*` — файлы пользователя: его карточки не меняй и не удаляй. Пользователь редактирует доску в браузере на `/canvas/` (нужен запущенный `serve.ps1`).

## Как отвечать на доске (карточки Claude)

Отвечай на вопросы, предлагай варианты и пересказывай, как понял задумку, прямо на доске:

1. Добавь карточку в массив `cards` в `brief/board.json`:
   `{ "id": "cl-<6 символов>", "type": "claude", "x": 0, "y": 0, "w": 300, "text": "..." }`
2. Ставь её рядом с карточкой, на которую отвечаешь (`x` = её `x + w + 40`, тот же `y`), а общие предложения — колонкой справа от всех карточек.
3. Ответ на вопрос начинай с «Ответ на: <первые слова вопроса>». Текст короткий, по делу; выбор оставляй пользователю («отметьте карточкой Решение»).
4. Добавь те же тексты в `brief/BOARD.md`, раздел `## Ответы и предложения Claude` (после «Вопросы»).
5. Открытый канвас подхватит изменения сам за ~3 секунды.

Только тип `claude`; исключение — найденные тобой референсы: карточки `link` (поле `url`) и `image` (поле `img`: `/brief/assets/<файл>`, скриншот положи в `brief/assets/`), их текст начинай с «✳ Claude:». Решения со статусом «Принято» ставит пользователь, не ты.
