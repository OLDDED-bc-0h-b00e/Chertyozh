# Публикация

Запускается только командой пользователя `/ship`. Аргумент (необязательный) — описание изменений: $ARGUMENTS

1. `git status` и `git diff --stat`. Покажи список изменённых файлов. В коммит не должно попасть ничего из `brief/` и `.claude/settings.local.json`.
2. Прогони скилл `site-check` (минимум `check.ps1` и консоль браузера). При ошибках — остановись и сообщи.
3. Предложи сообщение коммита (по-английски, коротко) и дождись «да».
4. `git add` конкретных файлов (не `-A`), `git commit`.
5. Если `git remote -v` пуст — публикации ещё нет. Не создавай репозиторий сам: объясни пользователю, как создать пустой репозиторий на GitHub, попроси ссылку, затем `git remote add origin <ссылка>` и предложи добавить `.github/workflows/pages.yml` (деплой папки `site/` на GitHub Pages, как в проекте MOONLIGHT). После этого запиши адрес репозитория и сайта в CLAUDE.md.
6. `git push origin main`, затем открой опубликованный сайт и проверь, что изменения на месте и консоль чистая.

Никогда: `push --force`, `reset --hard`, правка истории.
